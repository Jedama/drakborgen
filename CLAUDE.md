# Working on Drakborgen

A design project for a game, mostly done by brainstorming. Read `vision.md` first, then
`design.md` and `character-creation.md` as needed.

## Brainstorming

- Discuss before solving. Explore the problem with Dan; don't rush to a fix or on to the
  next topic.
- **When a topic is left behind, summarise what's still open into `ideas.md`.** Not during
  the discussion (it gets crowded fast), but at the point we move on: options left open
  side by side, a thing mentioned once in passing, a suggestion nobody answered, with who
  raised it and how it was received. Long chats get compressed and the nuance is lost; the
  file is what survives.
- `ideas.md` gets pruned regularly so it doesn't fill with outdated ideas. Deleting is safe,
  because git and `chats/` keep everything.
- Settled decisions go into `design.md` (or `character-creation.md`). Settling something
  from `ideas.md` means moving it over and noting that on the entry.
